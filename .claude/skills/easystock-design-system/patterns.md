# 화면 패턴

이지스톡 6개 화면의 레이아웃 + 정보 위계 + 인터랙션 가이드.

---

## 공통 레이아웃

```
┌─────────────────────────┐
│  Status bar (system)    │ ← 시스템 영역
├─────────────────────────┤
│  PaperHeader            │ ← 24px title + 캡션
│   - back button (옵션)  │
│   - title + subtitle    │
│   - action (옵션)       │
├─────────────────────────┤
│                         │
│  Scrollable content     │ ← px-4 pb-4
│                         │
├─────────────────────────┤
│  Tab Bar (5탭)          │ ← 고정 하단
└─────────────────────────┘
```

- 좌우 패딩: `16px`
- 헤더 → 첫 카드: `12~16px`
- 섹션 간 간격: `20px`
- 마지막 카드 → Tab Bar: `16~24px`

---

## 1. 홈 (오늘)

**목적**: "지금 내가 뭘 해야 하지?" 1분 안에 답.

**위계 순서** (위에서 아래로)
1. **헤더** — "안녕하세요, 지영님" + 오늘 날짜
2. **어제 요약 Hero 카드** — 매출 (30px) + 지난주 比 칩 + 순수익/마진율 분리선 + 주간 미니 차트
3. **오늘 할 일 (알림)** — 3~4개. 발주(red) > 만료(amber) > 입력(blue) 순
4. **이번 주 마진 TOP 3** — 리스트 카드
5. **마진 하락 메뉴** — red soft alert 1개 (있을 때만)
6. **빠른 입력** — [매입 등록] [판매 입력] 2-grid

**차트 규칙**
- 7일 막대 차트, 어제만 `ink-1`, 나머지 `ink-4`
- 요일 라벨 하단, 어제는 굵게

**비교 기준**
- "지난주 같은 요일" 매출 대비 % (절대 전일 X)
- 양수는 green chip, 음수는 red chip

---

## 2. 캘린더

**목적**: 월간 패턴 시각화 + 누락일 점검.

**위계 순서**
1. **헤더** — "2026년 4월"
2. **월 요약 카드** — 매출/순수익/일평균 3-grid
3. **캘린더 그리드** — 7×6, 셀 = 매출 인텐시티
4. **선택일 상세** — 메트릭 4-grid + 베스트셀러 + 매입(있으면)

**셀 규칙**
- 배경: 매출 인텐시티 → `color-mix(var(--ink-1) 0~14%, var(--card))`
- 좌상: 일자 (일요일 red, 토요일 blue, 평일 ink-1)
- 우상 도트: 매입(amber) · 누락(red)
- 좌하: 매출 만원 단위 숫자 (8.5px num)
- 선택: 배경 `ink-1`, 글자 `bg`
- 오늘: 보더 `c-blue`

**범례 필수** (그리드 하단)
- 매출 인텐시티 5단계 + 매입/누락 도트 설명

**누락일 처리**
- 셀에 "누락" 라벨 (red, 9px)
- 선택 시 상세 영역에 큰 red 알림 + 입력 버튼

---

## 3. 판매 입력

**목적**: 마감 후 5분 안에 끝나는 메뉴별 판매량 일괄 입력.

**위계 순서**
1. **헤더** — "오늘의 판매" + 날짜 + back
2. **자주 팔리는 메뉴** 라벨
3. **메뉴 행 카드** — 자동 정렬된 순서
4. **Sticky 합계 카드** (하단 고정)

**메뉴 행 규칙**
- 좌: 메뉴명 (`13.5/700`) + 가격·마진 (`11/500 ink-3`)
- 우: − 카운터 + 큰 숫자 + + 카운터
- 카운트 0인 메뉴도 표시 (자주 팔리는 순)
- 카운트 > 0이면 보더 `ink-1`로 강조 (선택 상태)
- 정렬: 지난 7일 누적 판매량 desc

**Sticky 합계**
- `position: sticky; bottom: 0;` + `padding-bottom: env(safe-area-inset-bottom)`
- 예상 순수익 (24px hero) + 마진율 칩
- 매출/원가 보조 표시
- 저장 버튼 풀폭 `bg-ink-1`

**입력 누락 방지**
- 마감 시간(밤 10시) 푸시: "오늘 판매 입력 1분이면 끝나요"
- 미입력 누적 시 알림 강화

---

## 4. 매입 등록

**목적**: 거래명세서 보면서 빠르게 입력.

**위계 순서**
1. **헤더** — "매입 등록" + back
2. **거래처/날짜 카드** — 분리선 사이로 2행
3. **품목 라벨** + 카운트
4. **품목 카드** (반복) — 재료명 + (수량/단위/금액 3-grid) + 단가변동 알림
5. **+ 품목 추가** (dashed)
6. **합계 카드** — 22px hero
7. **저장하기** primary

**거래처 / 날짜**
- 좌: 12px label "거래처" / "날짜"
- 우: select / 날짜 인풋
- 분리선으로 행 구분

**품목 카드**
- 우상에 `No. 01` 카운트 (10.5px num ink-3)
- 2개 이상이면 우상에 close 버튼

**단가 변동 자동 감지** ⭐ 핵심
- 같은 재료 매입 시 이전 단가와 비교
- 5% 이상 차이 → red soft 박스 + 인상률 표시
  ```
  단가 변동: 8,500 → 12,000원/kg  +41%
  ```

---

## 5. 메뉴 / 레시피

**목적**: 메뉴 원가/마진 점검 + 단가 변동 영향 즉시 확인.

**위계 순서**
1. **헤더** — "메뉴" + 카운트 + [+ 추가]
2. **카테고리 필터** — 칩 ("전체", "빙수", "커피", "논커피")
3. **메뉴 리스트 카드** — 클릭 시 아래 상세 변경
4. **레시피 상세 카드** — 메뉴명 + 판매가 + 마진율(대형) + 재료 리스트 + 합계
5. **단가 변동 알림** (해당 시)

**메뉴 행**
- 좌: 메뉴명 + 가격·원가 (`11/500 num ink-3`)
- 우: 마진율 Tag (green/neutral/red)
- 선택 시 `bg-card-hover`

**레시피 상세**
- 우상: 24px num 마진율 + "마진율" 캡션
- 재료 행: 이름 / 사용량 / 라인원가 (3컬럼, 분리선)
- 하단: 재료 원가 합계 (16px)

**단가 변동 알림**
- red soft 카드
- "딸기 단가 +40% 인상" + 원가 자동 재계산 안내

**카테고리 필터**
- horizontal scroll 가능
- 활성: `bg-ink-1 text-bg`
- 비활성: `bg-card border` + `text-ink-2`

---

## 6. 재료 (재고/소진 예측)

**목적**: "오늘 발주 뭐 해야 하지?" 즉답.

**위계 순서**
1. **헤더** — "재료" + 카운트 + [실사]
2. **상태 통계 3-grid** — 발주(red) / 주의(amber) / 안전(green) 카드
3. **재료 리스트** (소진 임박순 정렬)

**상태 카드**
- 큰 숫자 (24px) + 라벨 (10.5px)
- 색상 = main color

**재료 행**
- 상단: 재료명 + 현재 재고 / 우측: D-day 큰 숫자 + 상태 라벨
- 진행 막대 (1px, 7일 만점)
- 하단 캡션: "하루 평균 0.4kg 사용"

**상태 분류** (PRD §5)
- 🟢 안전: 5일+
- 🟡 주의: 3~4일
- 🔴 발주 필요: 1~2일
- ⚫ 소진 위험: 당일/익일

---

## 온보딩 (4-step)

**목적**: 5분 안에 가치 증명. 콜드스타트 처리.

**진행 바** — 상단 4-segment + back 버튼

### Step 1 — 환영
- 28px 타이틀 "이지스톡과 함께 시작해요"
- 3가지 가치 카드 (실시간 마진 / 소진 예측 / 5분이면 충분)

### Step 2 — 가게 정보
- 가게 이름 인풋
- 가게 유형 라디오 (빙수카페/카페/디저트카페)
- 선택된 옵션 = `bg-ink-1 text-bg`

### Step 3 — 템플릿 자동 등록
- "기본 메뉴 8개 자동 등록"
- 메뉴 리스트 미리보기 (08, 카페 음료 6종 추가)
- 사용자 변경 가능 안내

### Step 4 — 초기 재고
- 4개 핵심 재료 (딸기, 우유, 생크림, 인절미)
- 카드별: 현재 재고 + 며칠 사용
- "정확하지 않아도 OK · 첫 7일은 데이터 수집 기간"

**하단 고정 버튼** — "다음" / "시작하기" (마지막 step)

## 인터랙션 패턴

### 토스트
- 저장 직후 "저장되었습니다" 짧은 토스트 (2s)
- 이전 화면으로 자동 복귀 (purchase → home, sales → home)

### 로딩
- 스켈레톤 카드 (실제 카드와 같은 모양, `bg: var(--card-hover)`)
- 절대 스피너 사용 X (정적 느낌 유지)

### 빈 상태 (Empty State)
```tsx
<Card className="!p-5 text-center">
  <div className="text-[12.5px] font-medium text-ink-3">오늘은 아직 데이터가 없어요</div>
  <button className="mt-3 px-4 py-2 bg-ink-1 text-bg rounded-xl text-[12.5px] font-semibold">
    판매 입력하기
  </button>
</Card>
```

### 알림(Push) 전략
| 시점 | 내용 | 톤 |
|---|---|---|
| 마감 22:00 | "오늘 판매 입력 1분이면 끝나요" | 차분 |
| 발주 필요 09:00 | "딸기 2일 후 소진. 오늘 발주" | 긴급 |
| 단가 변동 즉시 | "딸기 단가 +41% 인상 감지" | 정보 |
| 재고 실사 월요일 09:00 | "주간 재고 실사" | 차분 |

## 한국어 UX 카피 톤

**좋은 예** (사장님 입말)
- "오늘 발주 뭐?"
- "분명 매출은 나오는데 통장에 돈이 없어요"
- "1분이면 끝나요"

**나쁜 예** (딱딱한 SaaS 톤)
- "데이터를 입력해주세요" → "판매 입력"
- "재고 부족 알림" → "발주 필요"
- "메뉴 원가 분석" → "메뉴 마진"

**원칙**
- 명사 위주 (동사형 라벨 최소화)
- 존댓말 대신 짧은 명령형 ("저장하기" > "저장해주세요")
- 숫자에 단위 (`원`, `잔`, `kg`, `일`) 항상 명시
